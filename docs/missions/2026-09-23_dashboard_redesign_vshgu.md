# Миссия (черновик, запуск после снятия паузы с test_hub): дизайн дашбордов под проект ВШГУ

Записано 23.09.2026 по просьбе владельца. Референсы — современные аналитические дашборды
(финтех-панели, Brand Analytics, BI-панели продаж): тёмный фон, карточки, кольцевые и площадные
графики с неоновыми градиентами, боковая навигация, переключатель светлой/тёмной темы.

## Цель

Перевести весь UI test_hub на единый визуальный язык «аналитического дашборда» и подогнать под
проект ВШГУ (логотип РАНХиГС, русские подписи, палитра статусов прогонов). Только UI и PNG-отчёты
бота, API не менять.

## Что должно получиться

1. **Каркас страниц.** Общий shell для всех страниц (`projects`, `project`, `coverage`, `xfail`,
   `share`, `admin`, `index`): слева сайдбар с логотипом и пунктами «Проекты», «Прогоны»,
   «Покрытие», «Xfail», «Расписания», «Настройки», «Выйти»; активный пункт подсвечен заливкой;
   внизу сайдбара переключатель темы. Сверху: приветствие/название проекта, поиск, роль пользователя.
2. **Темы.** Тёмная по умолчанию: глубокий тёмно-синий фон (#0f1223…#151a2e), карточки чуть
   светлее с мягкой тенью и скруглением 16px, тонкие разделители. Светлая: белые карточки на
   светло-сером фоне. Все цвета через CSS-переменные в `style.css`, выбор темы в localStorage,
   учитывать `prefers-color-scheme`.
3. **Палитра графиков.** Неоновые градиенты фиолетовый → розовый → голубой для линий/площадей и
   столбцов (как на референсах), статусы: passed зелёный, failed красный/розовый, skipped серый,
   xfail жёлтый/оранжевый, flaky фиолетовый.
4. **Дашборд проекта (`project.html`)** первым экраном:
   - ряд KPI-карточек: всего тестов, последний прогон (passed %), упало, длительность, флаки,
     xfail, каждая с мини-спарклайном и стрелкой изменения к прошлому прогону;
   - кольцевая диаграмма статусов последнего прогона с числом в центре;
   - столбчатая по прогонам: passed/failed по датам (как «Dissection» на референсе);
   - площадная с градиентом: длительность прогонов и тренд стабильности по дням недели;
   - кольца по областям (tests/api, tests/ui, e2e) в стиле «Spending parameters»;
   - список «самые долгие тесты» и лента последних прогонов с кнопками отчёта/шаринга;
   - кнопки запуска прогона в том же стиле (stage только по ручному подтверждению — не трогать).
5. **Покрытие и xfail** переоформить в том же стиле; treemap + таблица областей (уже запланировано
   в задаче d72149cb) должны использовать те же токены.
6. **Страница шаринга `/share/<token>`** — тот же стиль, без сайдбара и логина.
7. **Логотипы проектов** сохраняются: серые, цветные при наведении, клик ведёт в проект.
8. **PNG-отчёты бота** (matplotlib): тёмный фон, та же палитра, те же типы диаграмм.
9. **Мобильная адаптация**: сайдбар превращается в нижнюю панель/бургер, карточки в одну колонку.
10. **Анимации** лёгкие: появление карточек, рост колец и столбцов, без тяжёлых библиотек.

## Ограничения

- Библиотеки только с cdnjs (Chart.js UMD с закреплённой версией) либо свои SVG; единый стиль
  осей, подписей, тултипов.
- Не ломать существующие id/классы, на которые опираются тесты и JS; тесты `tests/` должны
  проходить, UI-smoke дополнить.
- Роли qa/manager/customer: заказчику показывать только читаемые карточки без кнопок запуска.
- README: раздел «Дизайн и темы» (Пэм).
