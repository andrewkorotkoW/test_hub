## Что должно получиться

1. **Карта продукта в проекте тестов.** Формат `tests/product_map.yml` (или `.json`) в репозитории
   тестов: зоны → узлы (экран/функция, id, название, ряд/колонка для раскладки) → связи (from → to) и
   привязка узла к тестам по префиксам путей/nodeid. Для VSHGU файл собирается из `product_map.json`
   и `features_vshgu.yml` и кладётся в `/Users/andreykorotkow/PycharmProjects/auto_tests_vshgu/tests/`
   (отдельный коммит в тот репозиторий, ветка `auto_tests_vshgu`). Для Demo — маленькая карта в
   `demo/tests/product_map.yml`. Если файла у проекта нет — страница показывает схему по дереву
   разделов тестов (зона на каждый `tests/api|ui|e2e`, узел на раздел), без падений.
2. **Бэкенд**: `app/core/product_map.py` — загрузка и валидация карты, расчёт статуса узла по
   последнему прогону стенда (светофор: зелёный «покрыто и проходит», жёлтый «частично:
   xfail/skipped», красный «есть падения», серый «тестов нет»; тем же способом, что в
   `xfail_registry`/`flaky`: nodeid → fullName → allure-results прогона), число тестов API/UI на
   узел и первые 5 тестов для всплывашки. `GET /api/projects/{name}/product-map?stand=` —
   зоны, узлы со статусами, связи, итог (N из M узлов покрыто, K без тестов, L с падениями).
   Кэш по `(project, run_id)`.
3. **UI**: `ui/coverage.html` — сверху кольцо «N из M экранов покрыто» и одна фраза, ниже схема:
   SVG на данных, зоны колонками, узлы-блоки только с названием и точкой-светофором, связи
   ортогональными линиями со стрелками, не проходящими сквозь блоки; интеграции полосой внизу;
   наведение — всплывашка с тестами; клик по узлу — переход в дерево тестов раздела (вкладка
   «Запуск» с выбранным разделом). Переключатель стенда. Нынешние treemap/таблицы областей/карта
   маршрутов уезжают вниз в раскрывающийся блок «Подробно» (не удалять — по ним есть тесты).
   Токены `DESIGN.md`, обе темы, цвет проекта — только кольцо и заголовки зон.
4. **Тесты**: загрузка/валидация карты, fallback без файла, расчёт светофора на фикстурных
   allure-results, API, UI-логика раскладки без браузера (`tests/js/...` как для других страниц).
   Существующие тесты проходят.
5. Скриншоты `docs/screenshots/coverage_scheme_{light,dark}.png` на проекте VSHGU и Demo.
