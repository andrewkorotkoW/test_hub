# Миссия: «Мобильный» прогон — флаг `mobile`, env `MOBILE=1`, рамка телефона для эфира и видео

Записано 06.10.2026 по решению владельца: «нравится живой прогон путей пользователя на мобилке — и в
test_hub сделать рамку под мобилку». Парная миссия в автотестах: `auto_tests_vshgu/docs/plans/
2026-10-06_mobile_android_mission.md` (режим `--mobile`/`MOBILE=1`, профиль Pixel 7 = viewport 412×915,
видео под размер устройства, тесты набора `mobile` — сквозные пути пользователя). Контракт эфира/видео
из `docs/missions/2026-10-01_live_stream.md` не меняется: плагин шлёт те же кадры и видео, просто
портретные 412×915 (кадр ≤ 960 по ширине — как и было).

## Что сделать

1. **Флаг прогона `mobile`** по образцу `live`: колонка `runs.mobile INTEGER NOT NULL DEFAULT 0`
   (миграция `_migrate_add_column`, как для `live` в `app/db.py:469`), поле `mobile: bool = False` в
   `RunCreate` (`app/schemas.py:84`), в ответах `GET /api/projects/{name}/runs` и `/runs/{id}` —
   `"mobile": bool(row["mobile"])` рядом с `"live"` (`app/routers/runs.py:100`). Раннер при `mobile=true`
   добавляет в env pytest `MOBILE=1` рядом с `TH_LIVE` (`app/core/runner.py:547-556`); без флага переменную
   не передаёт. `label` прогона, если пустой, подставлять «Мобильный (Pixel 7)».
2. **Форма запуска** (`ui/project.html:162` + `ui/project.js:90`, и страница сборки `project.html?set=`):
   галочка **«Мобильный (Pixel 7)»** рядом с «Эфир». При включении «Мобильный» галочка «Эфир» включается
   автоматически (её можно снять), подсказка под галочкой: «Прогон в мобильной вёрстке: viewport 412×915,
   touch, мобильный user-agent». Лимит эфира `TH_LIVE_MAX_TESTS` действует как раньше.
3. **Рамка телефона** на странице прогона (`ui/project.js:1167`, блок `.live-frame`) и на share-странице
   (`ui/share.html:27`): если `run.mobile`, кадр эфира и плеер видео рендерятся внутри рамки
   `.phone-frame` — портрет, соотношение 412×915, скруглённый корпус, тёмная полоса статус-бара сверху с
   временем из `ts` кадра, кадр масштабируется по высоте панели (`max-height`, без горизонтального
   скролла). Кнопка-переключатель «Без рамки» (localStorage) на случай, если нужен кадр во всю ширину.
   Без флага `mobile` — всё как сейчас, ни одного изменения в desktop-виде.
4. **Список прогонов и шапка прогона**: пилюля «Pixel 7» (как пилюля «Эфир»), в сводке прогона —
   «Устройство: Pixel 7». В Allure-отчёте ничего не трогать (параметр device пишет плагин).
5. **Расписания** (`app/routers/schedules.py`): поле `mobile` в расписании по аналогии с `live` только
   если это одно поле и один флаг в форме; если тянет за собой переделку формы — не делать, записать
   в отчёт.
6. **Тесты**: по образцу `tests/test_run_live_flag.py` — `mobile=true` ставит `MOBILE=1` в env и
   возвращается в API, `mobile=false` по умолчанию не ставит; миграция на старой БД; JS-логика рамки
   (масштаб, выбор рамки по флагу) — чистые функции в `ui/run-live-logic.js` с тестом в
   `tests/test_run_live_logic_js.py` (node v12: без `??`/`?.`). Smoke-тест страницы на наличие галочки.
7. **README**: раздел «Мобильный прогон» (флаг, env, рамка, связь с `--mobile` в автотестах).
