# Миссия: редизайн страниц test_hub — светлая стартовая, палитра проекта, страница проекта по макету

Записано 24.09.2026 по просьбе владельца. Продолжение миссии
`2026-09-23_dashboard_redesign_vshgu.md` (shell, темы, дашборд уже сделаны). Только UI
(`ui/*.html`, `ui/*.js`, `ui/style.css`) плюс минимальное хранение цвета проекта в БД/API.

## Обязательно перед началом

1. Открыть и изучить макеты страницы проекта в `docs/missions/redesign/` инструментом
   чтения изображений, не догадываться по именам файлов:
   - `redesign/variants/variant-N-*.png` — четыре предложенных варианта (1 Панель, 2 Лента,
     3 Сетка, 4 Таблица) в светлой и тёмной теме с разными цветами проекта; исходник —
     `docs/missions/redesign/variants/mockups.html` (открыть в браузере: переключатель темы
     и палитра работают, все графики построены на реальных данных test_hub);
   - файлы владельца прямо в `redesign/` (если появятся) — приоритетнее вариантов.
   Какой вариант выбран владельцем — указано в заметке к задаче; если заметки нет, брать
   вариант 1 «Панель».
2. Прочитать **`DESIGN.md` в корне репозитория** — это источник истины по токенам (темы, статусы,
   палитра цвета проекта, типографика, компоненты); `docs/missions/REFERENCES.md` — только визуальные референсы.
   Все цвета берутся из CSS-переменных, которые соответствуют DESIGN.md; исторические значения в
   `ui/style.css` привести к DESIGN.md в рамках части 1.
3. Посмотреть текущую реализацию тем: `ui/style.css` (`:root`, `[data-theme]`), `initTheme`
   в `ui/common.js`.

## Что должно получиться

### 1. Стартовая страница светлая, переключение на тёмную

- Страницы до входа в проект (`index.html`/логин, `projects.html`) по умолчанию открываются
  в **светлой** теме: белые карточки на светло-сером фоне, тёмный текст.
- Переключатель темы виден на стартовой странице и в сайдбаре, переключает на тёмную и обратно.
  Выбор хранится в localStorage и применяется ко всем страницам; `prefers-color-scheme`
  учитывается только пока пользователь не выбрал тему сам.
- Никаких «вспышек» тёмного фона при загрузке светлой страницы: тема проставляется до первой
  отрисовки.

### 2. Цвет проекта из палитры

- У каждого проекта свой акцентный цвет. В карточке проекта на `projects.html` и в шапке
  `project.html` — кнопка/точка выбора цвета: палитра из 8–10 готовых цветов (например
  синий #2563eb, фиолетовый #7c5cff, розовый #ff4fa3, голубой #38d6ff, зелёный #22c55e,
  оранжевый #f59e0b, красный #ff4d6d, бирюзовый #14b8a6, серый #8b93a7).
- Выбранный цвет применяется внутри проекта: акцент кнопок и ссылок, активный пункт сайдбара,
  обводка/заголовок карточек KPI, основной цвет графиков (градиент строится от цвета
  проекта). Статусы прогонов (passed/failed/skipped/xfail/flaky) палитрой не меняются.
- Цвет хранится на сервере: колонка `color` в таблице `projects` (миграция через
  `_migrate_add_column`), поле `color` в схеме проекта, `PATCH /api/projects/{name}` или
  отдельный `PUT /api/projects/{name}/color`. Менять цвет могут роли qa и admin; manager и
  customer видят цвет, но не меняют.
- Цвет работает и в светлой, и в тёмной теме (проверить контраст текста на кнопках).

### 3. Страница проекта по макету

- `project.html` перестроить по макету из `docs/missions/redesign/`: расположение блоков,
  пропорции, порядок секций, отступы, типографика — как на картинке. Уже сделанные виджеты
  (KPI, кольцо, столбцы, площадные графики, лента прогонов) переиспользовать, а не рисовать
  заново, но переставить и перекрасить под макет.
- Если на макете есть элементы, которых в test_hub нет (новые виджеты, фильтры) — сделать
  их на реальных данных из существующих API, без заглушек; если данных нет, написать в
  отчёте, что именно не хватает.
- Сделать скриншоты страницы проекта до/после (`docs/screenshots/redesign_*.png`) в обеих
  темах и с двумя разными цветами проекта.

## Ограничения

- API прогонов, покрытия, расписаний не трогать, кроме добавления цвета проекта.
- Бот и PNG-отчёты бота не менять.
- Существующие тесты `tests/` должны проходить; для цвета проекта добавить тест API
  (миграция, PATCH, права ролей).
- Коммиты небольшие, сообщения на русском.

## Приёмка

- Открыть `/` без localStorage — светлая тема; переключить — тёмная; перезагрузить — тёмная
  сохранилась.
- Выбрать цвет у проекта — сайдбар, кнопки, графики внутри проекта перекрасились, у другого
  проекта цвет свой.
- Страница проекта визуально соответствует макету, скриншоты приложены.
