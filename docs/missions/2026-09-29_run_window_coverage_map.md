## Что хочет владелец

1. **Вкладка «Запуск»: окно прогона выбранного теста.** Сейчас в `ui/project.html` карточка
   `#run-card` показывает только текстовый лог (`#run-log`, строки из `run_events` через
   `/ws/runs/{id}`). Нужно окно, в котором видно, **как идёт выбранный тест**:
   - для **UI-теста** — картинка: что сейчас происходит в браузере (кадры/скриншоты по шагам
     теста, в конце — видео/трейс Playwright, если есть), рядом название текущего теста и шага;
   - для **API-теста** — консоль: запросы/ответы и вывод pytest по текущему тесту, а не общий
     лог всего прогона;
   - переключение между тестами прогона (список слева/сверху со статусами по мере выполнения),
     выбранный тест подсвечен, окно показывает именно его.
2. **Карта покрытия по-новому.** Сейчас `ui/coverage.html`: сводка KPI, treemap «Тесты по
   областям», таблица областей, карта маршрутов. Владелец хочет другую карту покрытия —
   предложить варианты, где с одного взгляда видно: какие разделы проекта (дерево
   `sections`, страницы/маршруты из `routes.tsv`) покрыты, чем именно (UI/API/smoke), что
   не покрыто, что падает. Данные — только реальные из существующих API покрытия и статистики
   (`app/core/coverage.py`, `app/core/stats.py`, `/api/projects/{name}/coverage*`).
3. **Сначала макеты, потом код.** Владелец рисует поправки прямо на картинках.
