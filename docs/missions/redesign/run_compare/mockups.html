Вкладка «Причины» в окне прогона

При завершении прогона сообщение каждого падения классифицируется: 429 → троттлинг, 5xx/ReadTimeout/RemoteDisconnected → стенд не ответил, 401 → потеря сессии, остальное — тест или продукт. Светофор фильтрует список, таймлайн подсвечивает волны (≥5 падений одной инфраструктурной причины за ≤2 минуты). Падения «стенд» не попадают во «Флаки».
