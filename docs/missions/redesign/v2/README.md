# Чёткий макет v2 — два варианта на выбор владельца

`mockups.html` — один файл с переключателем страницы (Проекты / Проект / Покрытие),
варианта (A / Б) и темы, на реальных данных test_hub. 12 PNG рядом — каждая страница
× вариант × тема. Оба варианта соблюдают критерии чёткости из миссии: один акцентный
цвет экрана (цвет проекта), статусы только из семантической палитры, градиент не
больше одного на экран (только в графике длительности на «Проекте»), сетка 12 колонок
с карточками одной высоты в ряду, таблицы с липкой шапкой и зеброй, без bento.

**Вариант A «Панель»** — прямое воплощение раскладки из `DESIGN.md`: сайдбар 220px,
ряд из 6 KPI-карточек, кольцо статусов (300px) и столбцы по прогонам в одном ряду,
лента прогонов и известные дефекты — картами. Ближе всего к тому, что уже частично
реализовано, минимум риска при переносе в код.

**Вариант Б «Рабочий стол»** — топбар вместо сайдбара, KPI вынесены в тонкую полосу
чисел без карточной рамки (ещё тише декора), слева — фильтры, справа на весь экран —
таблица (прогонов / маршрутов / проектов) как главный рабочий объект, графики и
кольцо — вспомогательный компактный ряд под фильтрами. Плотнее, быстрее читается
инженером, но дальше от текущей реализации.

Без заметки с выбором к следующей задаче — берётся вариант A.
