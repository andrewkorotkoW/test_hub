Вариант A · Полосы по областям

Одна полоса на область: зелёный — прошли, красный — упали, жёлтый — известные дефекты, серый — пропущены. Отсортировано по числу тестов. Клик по строке — страница сборки этой области. Без колец и процентов — видно и объём, и состояние.

Вариант C · Карта плиток (treemap)

Площадь плитки — число тестов, цвет — состояние области (зелёный все прошли, жёлтый есть пропуски/дефекты, красный есть падения, серый не запускались). Крупное бросается в глаза, мелочь не мешает. Клик — сборка.
