Стенд

Sentry project/environment — для карточки «Ошибки продукта» и вкладки «Sentry» прогона. Потоки: 0 — последовательно; на k8s v2 с несколькими репликами 4 потока — 27 мин вместо 1,5 ч. Значение --env — только для проектов с «--env в раннере»: переопределяет, какой литерал раннер передаёт тестам, если он должен отличаться от имени стенда. Пароль для такого стенда — не здесь: общий на проект, задаётся на сервере переменной TH_STAND_PASSWORD_<ПРОЕКТ>.
