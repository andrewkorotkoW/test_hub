Статус теста — последний известный результат на выбранном стенде (дата и номер прогона — в строке), а не только самый последний прогон. Клик по строке раскрывает тесты области: ячейка — тест, клик по ней открывает связи теста на вкладке «Маршруты». Клик по имени области фильтрует там же карту маршрутов. «Только проблемы» (или клик по «✗ N» в строке) показывает упавшие тесты списком — с причиной, датой и прогоном.
