Статус теста — последний известный результат на выбранном стенде (дата и номер прогона — в строке), а не только самый последний прогон. Клик по строке раскрывает тесты области: ячейка — тест, клик по ней открывает панель связей. Клик по имени области фильтрует карту маршрутов ниже.

Колесо — зум, перетаскивание — панорама, клик по узлу — раскрыть/свернуть или открыть связи теста. По умолчанию видна только структура каталогов до папок областей — на свёрнутых узлах число тестов и полоска статусов внутри. «Развернуть всё» / «Свернуть всё» и «Только упавшие» — быстрая навигация по большому дереву; «Сбросить вид» возвращает автоподгон масштаба, если до этого зумили вручную.
