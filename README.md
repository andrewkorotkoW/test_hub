# test_hub — система запуска автотестов с ролями

Отдельный продукт (не agent_office): веб-система, где QA хранит и записывает тесты,
менеджеры и заказчики запускают прогоны и смотрят отчёты в реальном времени.

## Роли
| Роль | Может |
|---|---|
| **qa** | всё: добавлять/редактировать тесты, запускать, записывать сценарии «в реальном времени», видеть все данные |
| **manager** | запускать прогоны, видеть все данные; онбординг при первом входе |
| **customer** | только запуск и просмотр отчётов |

## Функции (по очередям)
1. **Каркас (миссия 1):** логин по паролю с тремя ролями (сессии, seed-пользователи), список проектов
   (проект = локальный git-репозиторий с pytest в `tests/` и своим `.venv`), выбор стенда (URL + учётка)
   при запуске, дерево тестов (файл → класс → тест), запуск всего/файла/теста, живой лог и
   Allure-подобный отчёт по прогону (WebSocket), история прогонов, очередь прогонов (один активный
   на проект, остальные ждут, отмена).
2. **Запись сценариев:** QA переходит в «режим записи», проходит сценарий в тестируемой системе
   (Playwright codegen), результат сохраняется как тест; редактор шагов (переименовать, добавить
   проверку, параметры).
3. **Покрытие:** список фич проекта, тесты помечаются фичами, страница покрытия (позже — «сад»/«планеты»).
4. **Онбординг менеджера, уведомления в Telegram, расписание ночных прогонов, ссылка «только чтение» для заказчика.**
5. **Подключение внешнего репозитория автотестов** (git clone/pull по URL) — позже, доступа пока нет.

## Стек
FastAPI + SQLite (sqlite3/SQLAlchemy) + WebSocket, фронт — чистый JS/CSS без сборки (`ui/`),
прогоны — `pytest` в `.venv` целевого проекта, e2e — Playwright, отчёты — `allure-pytest` results.
Референс-реализация запуска тестов и разбора allure-results уже есть в
`~/PycharmProjects/agent_office/app/core/testlab.py`, `scenarios.py`, `allure.py` — можно
переносить с адаптацией (это другой проект, импортировать напрямую нельзя).

## Запуск
```bash
.venv/bin/python -m app.main      # http://127.0.0.1:8700
.venv/bin/python -m pytest -q
```
Тестовые проекты для разработки: `~/PycharmProjects/bike_fit` (28 тестов, Streamlit UI) и
`~/PycharmProjects/Velo_bot` (53 теста). Секреты — только в `.env` (в .gitignore).
